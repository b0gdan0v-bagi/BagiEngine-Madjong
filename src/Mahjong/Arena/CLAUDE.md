# Arena/ — measuring the computer players

Namespace `BECore::Mahjong::Arena`, plain C++, no engine services. The program is `BagiMahjongArena` (`tools/arena/main.cpp` forwards `argv` and supplies the reader of log files); usage and examples: `docs/bot-arena.md`.

| File | What |
|------|------|
| `ArenaPlayer` | `ParseArenaPlayer(spec)`: `random`, a level `1` .. `10` (or `easy` = 1, `normal` = 5), `<level>:knob=value,...`; `kProfileKnobs` is the one place a `LevelProfile` knob gets a name (a new field without a row fails the build). `ChooseSeekWin` is the random seats' chooser (the same draws as `HandTestSupport.h`) |
| `ArenaHand` | `PlayArenaHand(seed, players, timing, worlds)` with the conventions of `ComputerStrengthTest` (wall, seat seeds, random-seat rng), so the old numbers come out; a non-null `WorldLoop*` plays a search decision's worlds through it (`SearchRun::RunWorlds`), the record is the same, the timed decision includes its worlds |
| `ArenaRun` | `RunArena(config)`: the same walls for every focus player, deterministic and **the same bytes at any `jobs`** (threads take whole seeds into slots of their own, merged in seed order; the timing sums the threads; a failure reports the lowest seed that failed); the tallies and rows also count how a hand ended for a seat (self-draws, lost hands, **gave the win** = another seat won on its discard or robbed its kong, standing score and points over the lost hands); **the seed (its four seat rotations) is the independent unit**. Two levels of threads: `min(jobs, count)` seed threads, each with its own `WorldThreads(jobs / seedThreads)` for the worlds of its search decisions (it appears only with fewer seeds than `jobs`; the total never exceeds `jobs`). `RunArena(config, ArenaHandPlayer)` is the seam for a test that makes a hand fail; the player gets the seed thread's `WorldLoop` |
| `ArenaWorlds` | `WorldThreads(n)`: a persistent pool (`n - 1` threads plus the caller) behind `ForEach(count, body)` / `AsLoop()`, the `WorldLoop` of `SearchRun`; one call at a time, the body must not throw; with `n` 1 a plain loop, no thread |
| `ArenaStats` | `MeanCi` (95 %, `kIntervalZ` 1.96), per-seed series, `PairedDifference` on the same seeds, `IsSignificant` (the interval excludes 0); `StandingScore` has no value for a seed without a lost hand and that seed is left out of the series and of a paired difference |
| `ArenaReport` | fixed-width text, fixed precision, no locale: the same result is the same bytes on every platform; the main table, then the table "how the hands end" (gave win %, self-draw % of wins, standing score, points/lost hand) and, with two focus players, its paired table; a new column goes in a table of its own, the main one keeps its bytes |
| `ArenaTable` | `--table-stats`: four Normal seats play each seed once, a `HandObserver` of `PlayArenaHand` (read-only, outside the timed decision) collects every own turn with the number of declared opponents, and `AddHand` tallies how often another seat wins in the following round (the source of `kOpponentWinPerRoundPermille`), the scores of winners and of standing seats, the share of wins on a discard; integers per seed slot, the same bytes at any `jobs` (`docs/own-draws-ev.md`) |
| `ArenaLogs` | the **log mode** (`--logs PATH`, tester match logs, `docs/tester-match-logs.md`): `LogSource` is the seam for the files (a function giving `(name, text)` of a folder or a file; `tools/arena/main.cpp` supplies `std::filesystem`, a test supplies strings), `ReadLogs` sorts by name and checks each, `CheckMatchLog(text)` = parse + `ReplayMatchLog` on a fresh `Match`: `ok` (a log that stops without `End` is ok, `complete` false) or a reason (`unreadable: line N: ...` / `does not replay: event N (Problem)`, so that a rules change that stops old logs replaying is told), `SummariseLogs` counts the corpus |
| `ArenaTester` | the person's seat against the bots (`--focus`, default `normal`, `random` refused): every `by: person` decision of a replayed log is a `TableView` from `Analyzer::PositionsOfSeat` (reused, so Arena includes `Analyzer/AnalyzerPosition.h`; numbers as there), a bot chooses by `ComputerPlayer(seed, profile).Choose(view)`. **Only the view goes into a bot**: `AnalyzeTesterDecision(view, logged, bot, seed)` has no model. A decision with one legal action is forced and not counted; the phases are `DiscardTurn` / `ClaimWindow` (a robbed-kong window included). The rng seed is `DecisionSeed(log name, hand, action index)` (FNV-1a, never the machine): one log, one answer. Equal = the same `HandAction`, `declareCalling` included. The **match** is the unit of the interval (`MeanCi` over the per-match shares; a match with no decision in a row is left out). The differences are against the first bot, in log order. Testers are not experts: the share measures how people play |
| `ArenaLogsReport` | the text of the log mode: `FormatCheckLines` (**`--check`**: `ok<TAB>name` / `bad<TAB>name<TAB>reason`, nothing else, name order; `tools/collect_logs.py` relies on it byte for byte), `FormatCorpusSummary` and `FormatLogAnalysis` (fixed width, no locale). `AnalyseLogs(logs, bots, jobs)`: threads take whole matches into slots of their own, merged in name order, **the same bytes at any `--jobs`**; a match that replayed but whose positions cannot be built is named under the agreement and counted, the exit code stays 0 (its real-game numbers, read from the events alone, still count). **Real-game numbers** (`RealGameOfMatch`): for every person seat-hand at a table with at least one computer seat, from the `Settlement` events (`wins` = winner, `points` = the person's `deltas`, `drawn`) and the logged `declareCalling` of the seat in that hand, the definitions of `ArenaTally`; the group is the computers' level `1..10`, or `mixed` when the table's computer seats differ (a person's own level does not count); a hand without a `Settlement` is not counted; the **match** is the unit of the intervals (`MeanCi` over the match's own share). It includes `Analyzer/AnalyzerReport.h` for `ActionNotation` |
| `ArenaCli` | `ParseArenaArgs` (`--focus`, `--others`, `--first`, `--seeds`, `--jobs` (0 = hardware concurrency), `--time`, `--logs`, `--check`, `--differences N`, `--table-stats` (refuses `--focus`, `--others`, `--time`, `--logs`), `--help`; with `--logs` the options that play seeds are refused, `--jobs` plays matches), exit codes 0 / 1 refused action or a path that cannot be read / 2 bad arguments; `RunArenaCli(args, source, output)` is what the program calls |

A change of a player is judged by its paired row. The reference numbers (Normal against random seats, the seeds that reproduce `ComputerStrengthTest`): `docs/bot-arena.md`; the search player's measurements and verdict: `docs/bot-search.md`.
