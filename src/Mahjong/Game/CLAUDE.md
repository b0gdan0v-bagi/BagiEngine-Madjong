# Game/ — the rules as plain C++

Classic Chinese mahjong for four seats. No scene, no renderer, no JSON: a test drives everything here directly. Every number of the rules is a named constant in its header; this file names the constant, the header holds the value.

## Wall conventions

The break, the loose reserve (refilled from the live tail) and the dead wall (never drawn) are this repository's assumptions; `Wall.h` documents them with their constants.

## HandModel

`Begin(settings, wall, seatWinds, roundWind)` deals and gives East the first tile (`BadSeatWinds` unless one East). A model never begun is a finished drawn hand, so a result exists exactly when the phase is `Finished`.

- **Phases:** `Discard` (the current seat holds one tile too many), `Claim` (a discard pending; `CurrentSeat()` is the discarder, the tile is `Discards().back()`), `RobKong`, `Finished`. Draws are automatic (`Receive`), so a seat only sees a phase it can act in. A bonus tile is laid open and replaced from the loose reserve; no tile to draw ends the hand `Drawn`.
- **Actions** return `std::expected<void, HandError>`; a refused action changes nothing. Nothing is compulsory.
- **Calling hand:** declared with a discard (`declareCalling`); the 13 that stay must wait (`WinningTiles(PlayerHand)`, meld copies counted). `callingAtDiscardCount == 0` means "declared with the first discard". A self-draw `DeclareWin` and a mahjong claim need it.
- **Claims:** a window opens only if some seat has a legal claim; each seat in it decides once (`Claim` / `Pass`). Chow only for the next seat (`chowFirst` = lowest tile, no honours, no wrap), pung needs two, kong three. Priority mahjong > pung/kong > chow; two mahjong claims: the larger `Offset` from the discarder. The claimer discards without drawing (after a kong it draws a loose tile first); the turn then goes to the seat after the claimer.
- **Kongs:** `DeclareConcealedKong` (four concealed equal tiles), `UpgradeKong` (only with the tile drawn this turn, not a kept copy, not right after a claim). Both draw a loose tile. An upgrade can be robbed (`RobKong`, mahjong only, by a declared seat the tile completes).
- **Result:** `HandResult { kind, winner, winningTile, source (Discard | SelfDraw | RobbedKong), from, loose, lastLiveTile }`. `loose` = the tile came from the reserve; `lastLiveTile` only for a self-draw on the last live-wall tile.
- `PendingTile()` is valid only while a window is open. `DrawnTile(seat)` only in `Discard` for the current seat that really drew (invalid after a claimed pung/chow; the loose tile after a kong).
- `LastClaimWindow()` is how the last `Claim` window was settled (`ClaimWindowResult`: winner, the `beaten` claims, a `serial` per window; `Begin` clears it, the robbing window leaves it): public data, so the table may show it to anyone.
- **Capture / Restore** (for the search player and the tests; the rules never call them): `Capture() -> HandState` is everything the model keeps as plain data (the wall as the three lists, not how it was broken); `static Restore(HandState)` builds it back and refuses, with a text naming what is wrong, a state no play could reach (tile counts, hand sizes for the phase, the window, the result). A new member of `HandModel` goes into `HandState`, `Capture`, `Restore` and the `Describe` of `HandModelRestoreTest`.
- `Moves()` is the append-only public log of the hand (`HandMove`: discards, claims, kongs; a concealed kong carries no tile; no passes, wins, bonus tiles).
- **Actions as data** (the surface of the computer player and the control API): `HandAction` with factories `MakeDiscard`, `MakeDeclareWin`, `MakeConcealedKong`, `MakeUpgradeKong`, `MakeClaim`, `MakePass`. `LegalActions(seat)` lists exactly what `Apply(seat, action)` accepts (tests hold "accepted iff listed").

## Scoring

`ScoreSeat(const ScoreInput&)` is pure, so a test builds a hand from notation. `ScoreBreakdown { won, lines, points, doubles, raw, limitHand, score }`: `raw = points << doubles` (saturating), `score = RoundUpToTen(min(raw, LimitCap(limit)))`.

- **Readings** (`ScoreReading`): the hand is read as sets and a pair; the reading with the largest `raw` wins, all lines come from one reading. A winning discard or robbed kong opens the set that holds the tile (each placement is a candidate); a self-draw keeps it concealed; the pair opens nothing. Four undeclared equal tiles are a concealed pung. A seat that does not win: melds, concealed pungs, its best pair; no chows looked for.
- **Points and doubles for everyone:** pungs and kongs (by terminal/honour, concealed, kong), pairs of dragons / own wind / round wind, bonus tiles; a chow scores nothing. Doubles: a dragon / own wind / round wind set, one suit (with or without honours), own / round flower. Each value is a `k*Points` / `k*Doubles` constant of `Score.h`.
- **Winner** (`ScoreWinner`): `Win`, `WinTileFromWall`, `OnlyWinningTile`; doubles `OnlyPungs`, `NoPoints`, `LittleFourWinds`, `LittleThreeDragons`, `TerminalsOrHonoursEverywhere`, `FullyConcealed`, `SeveralKongs`, `LooseTile`, `LastTile`, `RobbedKong`, `ObviouslyLast`, `CallingFirstHand`.
- **Limit hands** (`ScoreLimit`, `FindLimitHand`, winner only): score `LimitCap(limit)` as a single line, no other line read; first match wins in the enum order. Seven pairs (one suit or honours), concealed pungs of one suit, honours only, terminals only, all green, big three dragons, big four winds, four kongs, thirteen orphans, last tile 1 dot, loose tile 5 dots (the last two need a complete reading too).
- **Payments** (`Settle`): every loser pays the winner the winner's score, losers settle pairwise by the difference, any payment involving East is x`kEastPaymentFactor`; zero-sum; a drawn hand pays nothing. `SettleHand(model)` scores all four seats (also in a drawn hand, for the score table). `CountVisibleCopies`: copies in the pile and in open melds, not the winning tile, not concealed kongs.

### Scoring readings decided by the owner (2026-11-08)

Each is one place to change: no points = nothing but the 20 (`AddNoPoints`); obviously last = three other copies open (`CountVisibleCopies`, `kObviouslyLastCopies`); calling in the first hand = with the first discard; terminals everywhere counts the pair and chows with 1/9; a winning discard opens its set, a self-draw does not (`AddDecompositionReadings`); a flower both own and round doubles twice; order is points x 2^doubles, then the limit, then round up; only winning tile = the 13 wait on that one kind; limit hands: one suit means no honours, all green is pungs and a pair, big dragons' fourth set and pair one suit, four kongs open or concealed; a non-winner scores standing sets and best pair; every hand counts toward the 16/8 (`kEastRepeatCountsAsHand`); starting score and limit are settings. Flowers are never offered to a player (`flowers = false`; only the control `reset` turns them on).

## Match

`Start(settings, seed)` (`BadSettings` unless `handsPerMatch` is a positive multiple of 4): one seed is one match (the draw for East, then one `MakeWall` per hand); each seat starts with `startingScore`. `EndHand()` settles, moves the deal, deals the next hand or finishes (`MatchPhase::Finished`, the last hand stays in `Hand()`). `ApplySettlement` feeds made-up settlements (tests). Bookkeeping is pure: `NextProgress`, `RoundWindOf`, `IsMatchOver`. East wins: East deals again; another seat wins: the deal moves on. Every hand counts, an East repeat too. Round wind `Wind(handsPlayed / (handsPerMatch / 4))`. A drawn hand with `replayDrawnHand` (default) is replayed by the same East and does not count. After the match, `East()` / `Winds()` describe the hand that would come next.

## Computer player

A computer never gets the `HandModel`: it gets `MakeTableView(model, seat)` (own hand, the public table, `visible` copies, `legal`), so **no peeking is true by construction**; the hints and the control API reuse the view. It chooses only from `view.legal`; its own `MahjongRng` only breaks ties.

- **Turn** (`ChooseTurnAction`), first rule that applies: (1) `DeclareWin`; (2) declare the calling hand with the discard that leaves the most unseen winning copies; (3) a kong when the hand without it is no worse; (4) a declared hand keeps the wait with the most unseen copies; (5) `BestDiscard`: lowest `Shanten`, then highest `AcceptanceOf`, then lowest `KeepValue`, then the rng. Seven pairs / orphans / limit hands are never aimed at.
  The choosers are `DecideTurn` / `DecideClaim`, which return the action with the rule that decided (`TurnStep`, `ClaimStep`); `ChooseTurnAction` / `ChooseClaimAction` are their `.action`. The pieces of the rating are public and are what the choosers call, so there is one rule: `RateDiscards` (every kind, the chooser's order), `RateKong`, `RateClaims` / `IsBetterClaim`. `ComputerExplain` builds the explanation of the advice from those functions only, so a new rule of the chooser has to be reflected in `TurnStep` / `ClaimStep` (and there).
- **Claims** (`ChooseClaimAction`): (1) mahjong whenever listed; (2) a waiting hand passes everything else; (3) a claim is acceptable when it lowers the shanten, or keeps it for a value pung/kong (`IsValueTile`); best by shanten, acceptance, `ClaimRank`, rng; (4) else `Pass`. No defence (a discard that wins costs the discarder nothing extra).
- **Levels** (`ComputerLevel.h`): a number 1..10 (the owner, 2026-11-10); `ComputerLevel::Easy` is 1, `ComputerLevel::Normal` 5 (default). 2..4 are skip-knob profiles between them (each step significantly stronger than the one below); 6..10 are Normal placeholders, because no player inside the time rule beats Normal (`docs/bot-search.md`, "Levels"). Text and parse: `LevelText` / `TryParseLevel` (`1` .. `10`); the old names `easy` / `normal` only through `TryParseLevelName` (old saves and logs, the arena). A level is a `LevelProfile` of knobs (`skipAcceptancePercent`, `skipDeclarationPercent`, `skipClaimPercent`, `takeValueClaimsAtEqualShanten`, plus the search and own-draws knobs below); **a knob that is off draws nothing from the rng**, so Normal is exactly the player above and `ComputerLevelTest` pins it with golden scores (seeds 700..703). Hard was removed by the owner (2026-11-09) and stays removed: the search did not beat Normal (`docs/bot-search.md`). **A level per seat:** `SeatLevels` (`UniformLevels(l)`, one entry per seat) is the level of each seat; all four entries are kept, also those of seats a person plays (a seat that becomes a computer again takes the level it had), and only computer seats play them. Seat seeds do not depend on a level, so a uniform table plays exactly as the one-level table did. A player change is judged by the arena's paired row (`../Arena/CLAUDE.md`), not by a gtest of a few hundred hands.
- **Search** (`ComputerSearch.h`): three more knobs (`searchWorlds`, `searchCandidates`, `searchMargin`), **off in every level, none searches** (`searchWorlds` 0 draws nothing, so Normal and Easy do not move). When on, the Normal choice is the first candidate and the baseline; each candidate is played out in the same `SampleWorld`s with the same seed, and a candidate replaces Normal's only when its mean advantage is above `searchMargin` tenths of the standard error of the difference. `DeclareWin`, a mahjong claim, the pass of a waiting hand and a single candidate are never searched. A decision is a resumable `SearchRun` (`BeginTurnSearch` / `BeginClaimSearch`): begun = the one draw from the player's rng, after which it holds copies only and touches no rng or model; `Step()` plays one rollout; `SearchTurnAction` / `SearchClaimAction` are begin plus all steps, so a run stepped elsewhere gives the answer computed at once. **The per-world seam:** the worlds are independent, so `PlayWorld(i)` (const, pure) plays one and `Finish(worlds)` takes them in order; `RunWorlds(loop)` does both through a `WorldLoop` that the tool supplies (the arena's `WorldThreads`). **`BeginSearchOver(view, actions, baseSeed, worlds)`** is the same run over a list the caller chooses (no rng, no baseline, no two-candidate rule; `Candidates()`, `Values()`, `DroppedWorlds()` read it): the EV analyzer's way in (`../Analyzer/`), the same worlds and rollouts as a search with that base seed. `Game/` starts no thread, and the answer and the counters are the stepped run's whatever the order or thread count, because every seed is a function of the base seed and the world's index and the sums run in world order; `Step()` and `PlayWorld()` share the sampling and the rollout code, so they cannot drift. `ComputerPlayer::Begin(view)` is `Choose` in two halves: a search decision comes back as a begun run (the choosers take a `SearchHandoff*` and call `BeginTurnSearch` / `BeginClaimSearch` instead of the at-once function, so no precondition of the search is written twice), every other decision comes back as a ready action. `kSearchWorlds` / `kSearchCandidates` / `kSearchMargin` are the budget that fits the time rule of `docs/bot-search.md` (a profile that searches must keep the slowest decision at most 0.3 s in Debug); no level uses it. A `ComputerPlayer` built from a `LevelProfile` plays by it and reports Normal.
- **Own-draws value** (`OwnDraws.h`, `OwnDrawsValue.h`): `ValueDiscards(view, depth)` (step 5) and `ValueWaits(view)` (step 2) rate each candidate in milli-points as a pure function of a `TableView`: an expectimax over the seat's next draws from the unseen copies, the other seats only as the table `Alive`, a win and a standing hand scored by `ScoreSeat` / `Settle`'s constants. **Fixed point only** (probabilities over `kOwnDrawsProbBase`, `RoundedDiv`), so one view gives one answer on every platform; no rng, no static state. The knobs `ownDrawsDepth` and `ownDrawsPickWait` use it in `DecideTurn` (ties and an empty answer go to Normal's order and step), **off in every level**: no variant inside the time rule beat Normal (depth 2 and up are over 0.3 s in Debug). What it leaves out and the numbers: the header and `docs/own-draws-ev.md`.
- `ComputerTable`: four players, seat `i` seeded `SeatSeed(tableSeed, i)` and at `levels[i]` (`LevelOf(seat)`; the constructors of one level and of a `LevelProfile` make four equal seats; the arena builds no table from a level, its `ArenaHand` gives each seat its own profile); `NextActor`, `Step` (a refusal is a defect, returned as the error; it is `BeginStep`, the run stepped to its end, `FinishStep`, the halves a session steps on its own), `PlayHand`, `PlayMatch`. It knows no seat setup; that is `TableSession`.

## Table session

The one object every front end drives (control API, table component, HUD), so "who acts next" exists once. `StartMatch(settings, seed, seats, levels)` (`SeatLevels`; an overload takes one level for all seats; `Levels()`, `LevelOf(seat)`; `FirstComputerLevel(seats, levels)` is the lowest computer seat's: the one level a client that knows no levels per seat is told); `SeatSetup` of `Person | Computer` (`kDefaultSeatSetup`: seat 0 a person). `GetPhase()`: `Playing`, `HandOver` (waits for `NextHand()`), `MatchOver`. `Actor()` = `NextActor` while playing. `StepComputer()` (one action; the table component paces it; it is `BeginComputerStep()` + `Run()` of the `ComputerStepJob` + `FinishComputerStep(job)`, the halves a front end uses to compute a search elsewhere), `RunComputers()` (until a person must act; the control API), `PerformPerson(action)`, `NextHand()`. `Version()` grows on every visible change and never on a refused call. A match started through the non-const `GetMatch()` has no computers. **The two halves:** `BeginComputerStep()` draws the player's rng on the caller's thread and gives a job of copies only (nullopt, nothing drawn, unless `Playing` with a computer actor); `FinishComputerStep(job)` applies a done job exactly like `StepComputer`, but returns nullopt and changes and logs nothing when `Version()` or `StartCount()` is no longer the job's (a stale job is not an error, the caller begins again). `StartMatch(settings, seed, seats, const LevelProfile&)` seats a profile that is no level (the seam of the tests); `Levels()` and the log report the default level and a saved match does not keep the profile.

**Hot seat:** one person is always the `Viewer()`; none: `kNoSeat` (spectator); two or more: the person who acted last, reset when another person must act. `HandoffPending()` while that person is not the viewer; `Reveal()` fixes it.

**Resume:** `ResumeMatch(events, seats, levels)` (declared in `MatchLog.h`) puts the session where a log left it: the log is checked on a scratch `Match` first, so a log that does not replay returns its `ReplayError` and changes nothing; otherwise it is replayed with the session's sink as the echo, a fresh `ComputerTable` is seeded from the last `Start`, and seats, levels and viewer are set as `StartMatch` sets them. The computers' random state is not restored (the log has their actions, not their draws).

## Match log

`MatchLogEvent` (`Start` with seed, settings, seats, `levels`; `Hand` with the whole deal; `Action` with seat, `by` and the `HandAction`; `Settlement`; `End`). **The hook is `TableSession::SetLogSink`**, so every front end is logged. Refused calls, `Reveal` and bad starts are not logged. `ReplayMatchLog(events, match, echo)` replays on a fresh `Match` and reports the first event that disagrees; a log may lack its `Hand` and `End` events. The optional `echo` sink gets every applied event as a live session emits them (its own `Hand` / `End`, not the log's), and sees events before a later one is found wrong, so a caller that must leave no trace checks on a scratch match first. The JSON form and the file are `../CLAUDE.md` ("Match log").
