# tests/ — MahjongTests and the control smoke test

Rules of the engine: `engine/.claude/rules/tests-module.md`. New rule code gets a gtest case. A new feature gets a new test file when the existing one is big and shared. **This file lists helpers and what each file is for, not what each test checks** — the test names say that.

## Helpers (header only)

| Header | Use it for |
|--------|-----------|

| `StringsTestSupport.h` | `LoadShippedStrings`, `ReadShippedEntries`, `PlaceholderNames`, `ForEachLanguage`, `LongestText` |
| `ShippedScene.h` | the one place that knows where the scene is and expands the node refs (`LoadShippedSceneDocument`, `ShippedSceneXml`) |
| `MahjongTableTestSupport.h` | `MahjongTableTestBase`: the shipped scene, the game through `GameManager`, a `TurnRecordingRenderer` (a `RecordingRenderer` that records a turned draw as a `Texture` / `Rect` call over the screen rectangle, the unturned rectangle and the transform in `turned`) as big as the view (a view point is a pixel), `Lay(model)`, `Draw`, `Click`, `ClickHandTile`, `Tap` / `TapHandTile` (a click with `SDL_TOUCH_MOUSEID`: the touch regime), `HoverAt` (a motion through `UIInput`: a canvas that takes it keeps it from the table), `Element` / `ClickElement`, `ExpectPassesTheMatrix` (with the regions of the worst-case table of each case's view, `PublishTableRegions`: `OutsideRegion` / `MissingRegion` on every size), `ExpectWordsFit`; free `EmitAction`, `Var`. | `MahjongTouchTestSupport.h` | the size matrix: `ForEachMatrixWindow`, `LayOutInWindow`, `ToView`, `ExpectClearOfTable`, `MakeWorstCaseTableLayout(viewer[, window])`, `IsCompactWindow` (the rule with the window's bottom inset), `ActionsMayBeSmall` (the windows where `Actions` stays under 32 px: 1:1 portrait at 480 px, the near-square narrow window with side insets; clear of the hand is held there too), `SetOutputSize`, `PhoneWindows` / `ForEachTableWindow` (the matrix, the landscape phones at density 2.6 and two portrait phones), `TableLayoutFor` (the layout of the window's profile and shape), `IsMatrixWindow` (not a phone window), `SetWindow` (size and density the table's rule reads; `TearDown` gives the density back), `ExpectMatrixExceptTouchWhere`, `WordsThatDoNotFitOnTheMatrix`, `InputOf` / `SameSlots`, `kCompactWindowWidth/Height` (a nearly square narrow window that shows `ActionsCompact`, without insets; a square or tall output is the portrait view) |

| `ShippedTableLayout.h` | the shipped `config/TableLayout.xml` parsed from the source tree (`ShippedTableLayoutSpec()`): the layout tests run on it; `TableLayoutSpecTest` holds the global environment that makes it the active spec of the whole binary (the game's `config/` is not mounted) |
| `CoachCardTestSupport.h` | the variables of the coach's card: `CardVarNames`, `CardTexts(card)`, `CardVars`, `NoCardText`, `SetLongestCardTexts` (the size matrix) |
| `MahjongButtonSupport.h` | a button is one composed element (`UIInputClicker` / `UITextComponent`; segments and dropdown options are the same form): `ButtonAction`, `ButtonValue`, `IsButton`, `ElementText` (as written), `DisplayText` / `ShownText` (as shown), `TextOf`, `ShowsText` (not a `UIDropdown` header), `CollectTextControls` (a toggle row is one control: its caption is not asked). | `MahjongRoomsJudge.h` | `JudgeRoomMessage(text, seat)` (the offences of one text a room client received: the schema of a `rooms` list and of a view, no hand but its own while a hand is played, `result` only when it is over) and `RoomsJudgeLog`. `rooms_smoke.py` holds the same rule in Python: **change both together** |
| `MahjongOnlineTableTestSupport.h` | `MahjongOnlineTableTestBase`: the table fixture with the game's client in a room over `MahjongHubWorld` beside `HubPlayer`s (`StartRoom`, `Frame`, `PumpUntil`, `PlayUntil`, `Lists`); the match save goes to a temp folder named after the suite |

## Files

- **Rules (pure logic):** `Tile`, `MahjongRng` (golden values), `Seats`, `Wall`, `Deal`, `FixedWall`, `HandShape`, `HandWaiting` (pruned vs reference), `Shanten`, `HandModel{Turn,Claim,Kong,Moves,Actions,Playout,Window,Restore}`, `Score{Points,Doubles,Winner,Limit}`, `Payments`, `ScoreHand`, `Match`, `MatchPlayout`.
- **Computer players:** `ComputerView` (no peeking), `ComputerTurn`, `ComputerClaim`, `ComputerExplain` (every number held against the chooser's rating), `ComputerPlayer`, `ComputerLevel` (**golden scores of Normal, seeds 700..703**), `ComputerMatch` (whole matches, ~8 s Debug), `ComputerStrength` (vs random seats, the numbers in the file, ~3 s), `ComputerWorld` (a sampled world gives back the same view), `ComputerSearch` (~22 s), `OwnDraws` / `OwnDrawsValue` (the value of a discard from the own draws: views made by hand, no model); `ComputerMatch` also plays one search seat among three Normal ones.
- **Arena:** `ArenaPlayer`, `ArenaRun` (also the `WorldThreads` pool and the worlds level of the threads), `ArenaStats`, `ArenaCli`.
- **Arena, log mode** (`--logs`): `ArenaLogs` (verdicts, the corpus), `ArenaLogsReport` (golden report, the same bytes at any `--jobs`), `ArenaTester` (the person's seat against the bots; no peeking: equal views, one answer); the matches are made in memory with `ArenaLogTestSupport.h` (persons driven by a computer of a known level, logged `by: person`). `tests/collect_logs_test.py` (ctest `MahjongCollectLogs`) tests `tools/collect_logs.py` with a fake verifier.
- **Analyzer:** `AnalyzerRun` (EV, paired differences, no peeking), `AnalyzerPosition` (log and text positions), `AnalyzerReport` (golden text and JSON), `AnalyzerCli` (the reader is a lambda over strings).
- **Session, log, control:** `TableSession`, `ComputerThinking` (the background runner; needs the engine services, its parked-task cases are skipped under `BE_SINGLE_THREAD`), `MatchLog`, `MatchLogJson`, `MatchUpload` (the upload recorder with a fake sink), `BuildInfo`, `MatchLogFile` (its global environment points the log folder at a temp dir for the whole binary), `MahjongSave` (resume from a log, ~20 s Debug), `MahjongSaveStore`, `MahjongSaveGame` (its global environment switches saving off for the whole binary; the cases of the browser's storage states play them through `SetMatchSaveStorage` and a counting `SetSaveChangedHandler`, both restored in `TearDown`), `MahjongGameControl`, `MahjongSeatedGame` (the room adapter, no engine services), `MahjongOnlineTable` (the view read into plain data), `MahjongOnlineWords`, `MahjongOnlineClient` (the model over a scripted server), `MahjongOnlineHub` (four `OnlineClient`s over a real hub: a hand, a drop and a return, a resume), `MahjongRooms` (a `RoomHub` over it with a harness of the file's own: whole hands and matches, a drop and a return, hostile actions; every text judged, a leaky game as the negative control, the equal-views twins), `MahjongGame`, `MahjongGameUpload` (the recorder in the game). `MahjongOnlineList` (browsing the open rooms and joining from the list over the hub), `MahjongOnlineEntry` (`TextEntry`), `MahjongOnlineScreens` (the pages, the `Rooms` page included, over hub clients), `MahjongOnlineSave` (the `online` slot and the client in the game).
- **Pure scene logic:** `TableLayout` (**properties, not pixels**: tile sizes are read from the layout, a zone move in the file does not break it; the exact numbers are the named goldens `TheLandscapeTableKeepsTheNumbersOfItsDesign`, one per other shape), `TableRegions` (the zone and free regions the layout publishes), `TableSolver`, `TableLayoutSpec` (the reader, `Free` regions, `CheckTableLayoutSpec`, `OfferTableLayoutSpec`), `SeatPlates`, `CenterPanel`, `ActionButtons`, `MoveText`, `RulesText` (the drift guard: no digit outside a placeholder), `ScoreText`, `Hints` (also the card of the advice), `Coach` (the judge, the card of a note, the ledger), `CallingMarks`, `WindMarks`, `TileFlights`, `AnimationSpeed`, `TouchRegime`, `TapSelect`, `TileHover`, `TileSprites`, `EmblemSprites`, `IconSprites` (the library's `Icon_` sprites against the script's numbers), `TableLook`, `Strings`.
- **The scene (engine services, the table fixture):** `MahjongSceneFiles` (`kSceneNodes`: the one table of nodes; **the contract of the table canvases**: every element names a region or is a listed exception, no offset in units, every region name exists in every shape, the matrix and the clearance of the free ground), `MahjongUiStyle`, `MahjongTableUi` (faces per slot), `MahjongHandRack`, `MahjongTableInput`, `MahjongTableActions`, `MahjongTableHover` (the name plate of the tile under the pointer), `MahjongTableWindow`, `MahjongTableMarks`, `MahjongTableLostClaim`, `MahjongTableSpectate` (a watched match: all hands face up, no viewer mark), `MahjongTableFlight`, `MahjongTableSpeed`, `MahjongTableThinking` (a search seat on the table, through a search `LevelProfile`), `MahjongTableScreen`, `MahjongHud`, `MahjongOptions`, `MahjongHints`, `MahjongCoach` (the note on the card; a match played through the table counts its tally), `MahjongRules`, `MahjongEndScreen`, `MahjongTouchSize`, `MahjongTablePhone`, `MahjongTablePortrait` (the portrait view in the component: layout, clicks and taps, marks, flights, the compact rule), `MahjongTableShapes` (the same for the narrow and the wide view), `MahjongTableLayoutReload` (a new active spec shows in the next draw), `MahjongHudOnline` (the two online node files with no component), `MahjongOnlineTableScene` (the table of a room in the scene over the hub: the display pair, the clicks, the HUD of a room, the way out, a whole match played by clicks with a cut connection and the no-peeking check of every frame's draw; the game's own `HubPlayer` plays the first listed action, so a match needs computers to win a hand), `MahjongOnlineMirror` (the display copy and the move tracker), `MahjongOnlineHints` (hints and the coach at a room's table: the host's setting, the viewer's view, the line that says it), `MahjongUploadScene` (the consent question, the upload glue, the rows of `Options` and the pad of the nickname, over a fake poster and a temp prefs folder), `MahjongOnlineScene` (the panel in the scene; the clipboard cases over `FakeClipboard`, answered from `Clipboard::Update()`; its second half plays a room through the clicks over the hub, with a temp save folder and a game object made again), `MahjongTableAlloc` (a table drawn again unchanged, a pointer at rest on a tile too, the whole frame of a person's turn with the coach's card up (advice or note), of the score table with the tally row, and of the table of a room (a turn, a claim window, the ready check, the frozen table, with hints and the coach's cards up, both languages) and the pages of the online panel (menu, host and join forms, the pads, the lobbies) allocate nothing; only in a build with `ENGINE_PROFILER_ALLOC`, `macos-profile`).
- **`rooms_smoke.py`** (ctest `BagiMahjongRoomSmoke`): `BagiMahjongServer` on a free port with `--computer-delay-ms 0 --reconnect-grace-ms 300`, a hand with people and computers, a drop and a return with the token, four people; every text goes through the Python port of `MahjongRoomsJudge.h` (it checks itself on hand-made texts first). Uses the engine's `tools/rooms/smoke.py` (`RoomServer`, `Human`) loaded by path from `BAGI_ENGINE_DIR`. Does not build the executable; a missing one is a skip (77). By hand: `BAGI_ENGINE_DIR=engine python3 tests/rooms_smoke.py --exe <path to BagiMahjongServer>`.
- **`control_smoke.py`** (ctest `BagiMahjongControlSmoke`): `BagiMahjong --headless --control` on the real and the manual clock, over WebSocket with the engine's `tools/control/tests/smoke.py` (`BAGI_ENGINE_DIR`). Sets `BAGI_MAHJONG_SAVE_DIR` to a temp folder and checks a real restart (Continue offered, equal state, garbage save refused). Does not build the executable; a missing one is a skip (77). By hand: `BAGI_ENGINE_DIR=engine python3 tests/control_smoke.py --exe <path to BagiMahjong>`.
